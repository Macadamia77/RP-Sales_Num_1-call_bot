# record-decision — 결정 기록

결정은 **사람이 확정한 것만** 기록한다. 에이전트가 추천만 한 상태라면 `STATE.md` 미결정 사항 표의 메모란에 "추천: …"으로만 적는다.

## 절차

1. `STATE.md` 미결정 사항 표에서 해당 행의 상태를 `확정 (YYYY-MM-DD, 결정자)`로 바꾸고, 메모에 무엇을 골랐는지와 이유를 한 줄로 적는다.
2. 결정이 오래 유지될 내용이면 `AGENTS.md`에 반영한다.
   - 기술 스택·공급사 → "기술 스택과 개발 명령" 절
   - 구조 변경 → "확정된 구조" 절
   - 불변 규칙을 바꾸는 결정은 사람이 명시적으로 승인한 경우에만 고친다.
3. 상세 동작이 바뀌면 `docs/spec.md`의 해당 절을 고친다.
4. 결정으로 막혀 있던 마일스톤·할 일이 풀리면 `STATE.md` 마일스톤 메모와 다음 할 일을 갱신한다.
5. `STATE.md` 작업 내역의 이번 세션 항목 `결정:` 줄에 적는다.
6. 커밋 메시지 예: `[claude-B] decision: D5 백엔드 Python 확정`
