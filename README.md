# RP-Sales_Num_1 call_bot — 관리사무소 연락처 수집 콜봇 (프로토타입)

부동산·건물 내 점포에 전화를 걸어 **관리사무소 전화번호를 묻고, 들은 번호를 다시 읽어 확인받은 뒤, 대화 근거와 함께 저장**하는 AI 전화 에이전트의 프로토타입입니다.
설계는 `AI 전화 에이전트 구축 설명서 v1.0 (2026.09.28)`을 따릅니다.

> 유료 서비스 없이 바로 실행됩니다. 전화 대신 **텍스트/브라우저 음성 시뮬레이터**로 통화 흐름을 검증하고,
> 키를 넣으면 Twilio 실제 전화·외부 LLM·본인 목소리 TTS로 바꿀 수 있는 구조입니다. **OpenAI는 사용하지 않습니다.**

## 빠른 시작

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn callbot.app:app --reload
# → http://localhost:8000
```

1. **① 작업 · 통화 테스트** 탭에서 작업을 추가하고 `시뮬레이터 통화`를 누릅니다.
2. 내가 **전화 받은 점포 직원** 역할로 답합니다. (예: `공이, 일이삼사에 오육칠팔이요` → 봇이 `공 이, 일 이 삼 사, 오 육 칠 팔, … 맞을까요?`)
3. Chrome에서 🎤 버튼을 누르면 말로 답할 수 있습니다. 봇이 말하는 중에 끼어들면 봇 음성이 멈춥니다(말 끊기).
4. **② 결과** 탭에서 확보 번호·확인 상태·근거 발화를 보고, 사람 검토(승인/반려), CSV 다운로드를 합니다.

테스트: `pytest` (가이드 10장의 T01~T10 시나리오 포함, 43개)

| 대화 판단 LLM | LLM + 상태 관리 | **규칙 기반 해석기**(기본, 오프라인) · Ollama(로컬) · Gemini 무료 등급 · Claude(유료) — 모두 실패 시 규칙 기반으로 자동 대체 | 무료 ~ 유료 |
| 음성 합성 TTS | 본인 목소리 TTS | 브라우저 기본 한국어 음성(기본) · edge-tts(무료, 복제 불가) · ElevenLabs(유료, 본인 목소리 복제) | 무료 ~ 유료 |

| 관리 화면 | 웹 | 작업·통화·결과·템플릿(버전 관리)·목소리 화면 | 무료 |

### 가이드 원칙을 코드로 강제한 부분

- **번호는 LLM이 아니라 코드가** 추출하고 낭독합니다. LLM이 만든 문장에 숫자가 있으면 버립니다.
- **성공 = 번호 제공 발화 + 봇 낭독 + 상대 확인 발화**가 모두 연결됐을 때만. 근거가 없으면 성공 처리를 막습니다.
- 지역번호가 빠지면 **묻고, 채우지 않습니다**. 정정("마지막은 팔이 아니라 구예요")이 오면 이전 확인을 무효화하고 다시 읽습니다.
- 낭독이 **중간에 끊긴 뒤의 "네"는 확인으로 치지 않고** 다시 읽습니다. 봇 발화는 생성/재생/중단 상태를 따로 기록합니다.
- 상대가 "다른 번호로 전화해 봐"라고 해도 **소개 번호로 기록만** 하고, 발신은 서버 작업 목록·허용 목록을 따릅니다.
- 거절 → 재발신 제외. 작업당 진행 통화 1개(중복 발신 방지), Twilio 웹훅 중복 수신 시 한 번만 처리.
- 첫 인사에 **AI 대리 통화 안내**를 고정 문구로 둡니다(템플릿 저장 시 검사).
- 실제 발신은 `CALL_ALLOWLIST`에 있는 번호, `CALL_HOURS` 시간대에만.

## 폴더 구조

```
callbot/
  phone.py          번호 추출·정규화·검증·정정·낭독 문장
  dialog.py         통화 한 건의 상태 머신 (인사→번호 요청→재확인→저장·종료, 예외 처리)
  templates.py      기본 대화 템플릿 + 고정 규칙 검사
  llm/              해석기: rule_based(기본) / providers(ollama, gemini, claude)
  tts/providers.py  mock / edge / elevenlabs
  telephony/twilio.py  Twilio 발신·TwiML·서명 검증
  service.py        작업 실행·발신 정책·결과 확정
  db.py             SQLite 저장소
  app.py            REST API + Twilio 웹훅
  static/           관리 화면
tests/              phone / dialog(T01~T10) / API
```

## 실제 전화로 테스트하려면 (마일스톤 01·04)

1. Twilio 계정, 발신용 Twilio 번호(또는 검증된 번호)를 준비합니다.
2. `ngrok http 8000` 등으로 외부 주소를 만들고 `.env`에 넣습니다. (`.env.example` 참고)
   ```
   TWILIO_ACCOUNT_SID=... TWILIO_AUTH_TOKEN=... TWILIO_FROM_NUMBER=+1...
   PUBLIC_BASE_URL=https://xxxx.ngrok-free.app
   CALL_ALLOWLIST=010-1234-5678   # 처음엔 본인 번호만
   ```
3. 작업의 "전화할 번호"를 본인 번호로 두고 `실제 전화`를 누릅니다.

Twilio 연동은 목업 없이 작성했지만, **이 환경에서는 계정이 없어 실제 발신은 검증하지 못했습니다**(웹훅 흐름은 테스트로 검증). Twilio 한국 가이드에 따르면 국내 발신번호 표시는 보장되지 않으므로 "연결되는지"와 "원하는 번호가 표시되는지"를 따로 확인해야 합니다.

| 항목 | 선택지 | 비고 |
|---|---|---|
| 전화 공급사 | Twilio / 국내 CPaaS(예: 발신번호 표시가 중요하면 국내 사업자) | 한국 발신·발신번호 표시 조건을 공급사에 먼저 확인 |
| 본인 목소리 | ElevenLabs IVC(유료, 구현됨) / 로컬 오픈소스 복제(OpenVoice V2·XTTS 등, 미구현) | 오픈소스 모델은 GPU·라이선스(상업 이용 가능 여부) 확인 필요 |

| 법·정책 | AI 대리 통화 안내, 녹음·대화록 보관, 자동발신 조건 | 실서비스 전 확인 필요 (이 프로젝트는 법률 판단을 대신하지 않음) |
